outfit

Equip a workstation, development environment, compute node, or media node from reusable profiles.

First alpha · Preview changes before applying · Keep credentials in 1Password

Install the CLI

curl -fsSL https://johnhenning.dev/tools/outfit/install.sh | sh

Preview first

curl -fsSL https://johnhenning.dev/tools/outfit/profiles/workstation.sh | sh -s -- --dry-run

Run without installing Outfit

curl -fsSL https://johnhenning.dev/tools/outfit/run.sh | sh

Or start from a known profile:

curl -fsSL https://johnhenning.dev/tools/outfit/profiles/compute.sh | sh

Profiles: workstation, development, compute, media. Each uses a temporary CLI and opens setup for review. Advanced options let you choose software alternatives.

Windows and WSL

irm https://johnhenning.dev/tools/outfit/install.ps1 | iex
irm https://johnhenning.dev/tools/outfit/profiles/workstation.ps1 | iex

Run the Unix commands inside your chosen WSL distribution for Linux development tools.

Make it yours

Start from public templates. Fetch your private profile overlay after signing in to GitHub. Authorize 1Password when you need credentials; private keys and tokens stay out of the profile repos.

outfit personalize --repo johnhenning/outfit-personal
outfit doctor

CLI source & documentation · Public profile templates · Inspect installer

This alpha reports manual installers and configuration steps. GPU drivers, media storage/services, and WSL provisioning need explicit setup. Cross-platform builds do not imply every fresh-machine install has been verified.
